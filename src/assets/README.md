# Assets Folder

Поместите сюда исходную иконку для favicon.

## Требования к favicon.png:

- Размер: **минимум 512x512 пикселей** (рекомендуется 1024x1024 или больше)
- Формат: PNG (с прозрачностью желательно)
- Файл должен называться `favicon.png`

Плагин `favicons-webpack-plugin` автоматически сгенерирует все необходимые размеры и форматы:
- favicon.ico
- apple-touch-icon
- android-chrome icons
- manifest.json
- и другие необходимые файлы

Всё это будет автоматически добавлено в HTML через теги `<link>` и `<meta>`.
